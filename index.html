See what an all-atom RNA token knows.

RNAcoder turns every residue, base pair and dinucleotide of an RNA 3D structure into a compact token, learned by autoencoders that must rebuild all atoms from it. Browse the three token spaces of the pretrained encoders and see any token decoded back into 3D.

How to read the explorers

  1. Each point is one token. Its position comes from a UMAP of the token vectors; nearby points have similar local all-atom geometry.
  2. Hover a point to see the structure the decoder rebuilds from that token alone, red, over the input structure, green.
  3. Click to pin a point, and follow the link to its PDB entry.
  4. Change the colouring to check which properties the token space organises by.
